# Translations

Each `*.inc.php` file translates Adminer to one language.
You can edit it right on GitHub which creates a pull request for you.

- A line ending with a comment like `// Claude Opus 5` was translated by an AI model and nobody has reviewed it yet.
  Fix the translation if needed and delete the comment.
- A message missing in the file is displayed in English.
  [xx.inc.php](xx.inc.php) contains all messages, some with an explaining comment.
  Put the translation to the same place.
- `php lang.php [no-plugins] <lang>` run in the repository root adds the missing messages to your file and checks its placeholders and punctuation.
- Add 🔔 to a feed reader to watch all changes of a translation.
- To add a new language, follow [these steps](https://www.adminer.org/en/translation/).
