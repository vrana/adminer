# cPanel
Mimics Jupiter, the default [cPanel](https://cpanel.net/) theme, for hosting providers offering Adminer next to the other database tools in cPanel.

Colors, fonts, cards, buttons and form controls are taken from the Jupiter stylesheets shipped with cPanel 11.136.

Light only, the same way cPanel is by default.
